# ADR-0011: Name: Barnraise

- Status: accepted
- Date: 2026-11-23

## Context

The system needs a short, pronounceable name for the command, the module and the repository.

## Decision

The product is **Barnraise**, command `barnraise`. "Barn raising" is the American community effort where neighbours build a barn together; several agents and machines build one project together. The name was free on GitHub.

## Consequences

- Module `github.com/leandrodaf/barnraise`; ids and refs use the `br` prefix (`br/I-42-…` branches, `br.<project>.…` NATS subjects).
- Trademark and domain checks are still open.

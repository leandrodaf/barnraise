Map of this project's Barnraise knowledge; read it first.

- `constitution.md` — project rules that always apply (owner changes it).
- `areas.yaml` — area → folders, screens, contracts, standard.
- `glossary.md` — project terms.
- `standards/<area>.md` — one standard per area.
- `decisions/D-<n>-<slug>.md` — decisions (ADRs); follow only `status: active`.
- `goals/G-<n>.md` — goals with their measurable end.
- `memories/M-<n>-<slug>.md` — typed memories with a review date.
- `roles/<role>.md` — role prompts (override the template).

Commands: `barnraise context I-<n>`, `find "<text>"`, `related <id>`, `why <file>:<line>`,
`history <symbol>`, `rules <path>`.

# ADR-0024: License: Apache-2.0

- Status: accepted
- Date: 2026-11-23

## Context

Barnraise is open source and should be usable by companies, with a clear patent grant.

## Decision

Barnraise is licensed under the **Apache License 2.0**, copyright 2026 Leandro Ferreira.

## Consequences

- Contributions are accepted under the same license.
- Third-party ideas are reimplemented, never copied (ADR-0018), so there is no license mixing.
